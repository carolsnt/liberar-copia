# Extensão Liberar Cópia

Uma extensão simples para navegadores que permite copiar conteúdo de sites que normalmente restringem esta funcionalidade.

## Instalação

1. Faça o download do código da extensão (formato ZIP)
2. Extraia o arquivo ZIP em uma pasta de sua preferência
3. No seu navegador, acesse as extensões (normalmente em `chrome://extensions/` ou `edge://extensions/`)
4. Ative o "Modo do desenvolvedor"
5. Clique em "Carregar sem compactação" 
6. Selecione a pasta onde você extraiu os arquivos da extensão

## Como usar

Após instalar a extensão, basta navegar para qualquer site e a funcionalidade de cópia (Ctrl+C) estará liberada mesmo em conteúdos restritos.

## Compatibilidade

- Google Chrome
- Microsoft Edge
- Outros navegadores baseados em Chromium

## Aviso legal

Esta extensão é fornecida apenas para fins educacionais e de uso pessoal. Utilize-a com responsabilidade e respeite os direitos autorais e termos de uso dos sites que você visita.
